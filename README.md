# Vortex-ClawMachine
Vortex is a working small claw machine powered by an esp32. Built for Hack Club Fallen 2026

It is intended to be used as a fun tiny claw machine that can fit on a desk. It uses a large glowing button, along with a fun arcade joystick to control a claw that can pick up small prizes.

# Features & Design
This small claw machine that can fit on your desk uses a wall power supply and uses stepper motors to control the main claw carriage. 

It uses an XY gantry design using 2 lead ball screws, inspired by 3D printers. The claw machine also includes a small prize chute that can handle prizes up to 6 cm wide.
